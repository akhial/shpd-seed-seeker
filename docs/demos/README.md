# Artifact transmutation demos

- [Web](artifact-transmutations-web.mp4): add Ethereal Chains with up to four
  transmutations, search through floor 19, and inspect the full starting deck
  as an always-visible icon row with its matching target highlighted. Recorded
  in local Chrome.
- [Android Canary](artifact-transmutations-android.mp4): open Scout from a floor-19
  artifact query and scout `AAA-AAA-AAA`. All eleven starting artifacts fit on
  one compact line, without a title, numbers, expand/collapse control, floor
  picker, or hint paragraph. Recorded on the emulator and played at 2× speed.

The macOS demo was skipped at the requester's direction because the desktop was
locked. The native app builds and its Swift tests pass.
